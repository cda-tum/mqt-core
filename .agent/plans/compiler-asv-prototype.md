# Compiler asv prototype

Status: complete; local prototype and RTD integration implemented. Remote
publication is not activated. Dedicated-machine execution is covered by
[the runner record](compiler-benchmark-runner.md).

## Scope and decisions

Use `mqt.core.bench` GHZ, QFT, and Bernstein–Vazirani generators at 4, 8, and 16
total qubits. Generate structured QC outside the timed region, then copy and
compile through the QCO target pipeline to native QC. U/CX all-to-all and line
targets use the Base QIR payload contract to unroll static loops.

Compilation time includes copying, QC/QCO conversion, compilation, conversion
back to native QC, and result disposal. Quality analysis uses the existing QC
two-qubit gate counter and Qiskit depth. U/CX gates have unit depth, terminal
measurements have zero depth, and barriers synchronize wires. Dynamic circuits
and nonterminal measurement are outside this prototype.

The static MQT overview decodes asv v2 results, preserves unavailable values and
raw timing samples, and compares only matching environments, cases, and metric
versions. It links to the original asv explorer. Nox provides run, build, and
serve commands; local results persist in `.asv/results/` outside build output.

Sphinx embeds the overview in `docs/compiler_benchmarks.md`. Scoped CSS inherits
Furo typography and theme colors. Relative assets work under RTD version paths.
The existing RTD build publishes the checked-in `benchmarks/results/` snapshot;
it does not measure performance. The snapshot contains two actual compiler
revisions with six timing samples per case. The compiler APIs remain unchanged.

## Validation and limits

Reproduction commands and metric definitions are in `benchmarks/README.md`.

- Focused compiler, decoder, export, and documentation-link tests: 37 passed.
- Isolated `compiler-benchmarks` Nox run across revisions `626e8b5e` and
  `2caec49d`: 108 valid metrics, with six timing samples per case.
- Full `uvx nox -s lint` passed; new files are also checked explicitly.
- Sphinx HTML generation succeeded. The final whole-site link check reports 238
  links from `cpp/doxygen_crawl.html`, generated by local Doxygen 1.12.0. No
  dashboard links fail. The Doxygen configuration and extension are unchanged.
- Browser checks covered Furo light/dark themes, circuit/connectivity filters,
  baseline selection, a 390-pixel viewport without page overflow, and WebMCP
  filter selection with invalid-input rejection. The nested asv chart loaded
  with the selected circuit and topology and no browser console errors.

These are developer-machine measurements, not a calibrated regression gate.
Mapping trials depend on available CPUs, and generator changes can alter the
input. Future comparisons need fixed inputs and machine conditions. No remote
RTD build has been triggered.
